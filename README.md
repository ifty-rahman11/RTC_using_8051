# RTC_using_8051
A real time clock implementation using 8051 microcontroller in assembly.

Features:
1. Real time clock monitoring using RTC module.
2. Initialize time, data and day name.
3. Automatically identify the temperature using DHT11
4. A power saving mode: Turning off the display but RTC keeps running.
5. A reset option.
6. Hardware Implementation using 8051 microcontroller trainer board.
